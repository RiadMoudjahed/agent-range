Your last pentest probably did not cover this

A standard test checks your API. It rarely checks what happens when a customer email tells your agent to call that API for them. These are the patterns I test for, shown on a fictional shop:

Someone else's data

The agent's tools use one shared service account, so the only thing protecting other customers' records is a sentence in the prompt.

"Show me order B-2001" returned another customer's delivery address and gate code.

A ticket that moves money

An internal agent reads text that outsiders wrote, and it holds a tool with real effect.

A support ticket addressed to the triage agent got a refund ten times over its policy limit approved.

Rules that only live in the prompt

Refund limits, approval steps and data boundaries written as instructions to the model instead of checks in code.

"Never refund more than the order total" held until someone asked politely with a reason.

All three come from Larkspur, my open-source practice lab. You can reproduce them yourself.

Questions

Do you test in production?

Staging by default. Production only with written approval, agreed time windows and test records created for the purpose. No destructive actions without your sign-off for each case.

Which models and frameworks do you cover?

Any agent that calls tools, whatever the model provider or framework. The weaknesses are in how tools, credentials and untrusted content are wired, and that is what I test.

We only have a chatbot over public docs. Do we need this?

Probably not. If it has no tools and no private data, an automated scan is a better use of your budget. I will say so on the call.

What if you find nothing serious?

You get a report showing what was tested and how, which is what customers and auditors ask for. A clean result from a documented test is worth having.

Is this a guarantee that our agent is secure?

No test can promise that. It is a time-boxed, point-in-time assessment that finds what an attacker would most likely find first, and checks that your fixes work.

How soon can you start?

I take one or two engagements a month so each gets full attention. The booking page shows my open times for the review call.
